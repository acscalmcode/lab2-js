
# Lab 2 – Interactive Portfolio Enhancements

## Project Description

This project is an updated version of my Lab 1 personal portfolio website. I have added a feedback form and user friendly validations using JavaScript.

## Target Grade

**Grade 3**

## How to Run
1. Download or clone this project repository.
2. Open the downloaded project folder.
3. Open `index.html` in a web browser.
4. Open the feedback form by clicking on `feedback` in menu.
